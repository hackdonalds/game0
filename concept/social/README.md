# Social

> To be planned in its own session.

Guilds, reputation, grudges between peoples, chat and friends, and how players and NPCs relate.

## Design rule: built to extend

New peoples will join later, so nothing social is hard-coded to the current three.

- Each people is **data**: its homeland, culture, starting relations with every other people, and NPC behaviour.
- Relations between peoples are a table, so a new people adds a row and a column.
- Reputation works the same way for peoples, towns and guilds.

- Reputation with peoples, towns and the Accord
- How grudges between peoples show up in play
- Friends, groups and chat across shards
