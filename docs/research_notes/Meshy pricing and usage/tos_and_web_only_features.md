# Meshy.ai: Terms of Service on Automated Use, and Web-App Features With No API Equivalent

Research date: 2026-10-31. Sources were fetched directly (raw HTML/Markdown via curl). Nothing was signed in to and no account was changed.
Documents and versions:
- Meshy Terms of Service, https://www.meshy.ai/terms-of-use, "Last Updated: September 19, 2026"
- Meshy Acceptable Use Policy (AUP), https://www.meshy.ai/acceptable-use-policy, "Last Modified: November 11, 2024"
- Meshy web app docs (https://docs.meshy.ai/en/webapp/...), web app changelog through September 2026
- Meshy API docs (https://docs.meshy.ai/llms.txt, /llms-full.txt, /api/pricing.md)

## (A) Is driving the Meshy web app with browser automation (AI agent clicking the UI in the user's own signed-in Chrome, human pace, own account) permitted, restricted or prohibited?

### Takeaway
No clause names browser automation, bots, scraping or AI agents. The closest clause is in the AUP: Meshy "may disable accounts" for "Using unauthorized automated or scripting processes (such as bulk or automated uploading of content through a script)". An agent clicking the web UI is very likely an "automated ... process". The word "unauthorized" is never defined, and Meshy's docs present the API/MCP server/CLI as the sanctioned automation route. So: **restricted / grey area with real account-disablement risk, not explicitly prohibited**. Nothing says the API is the only allowed way to automate, and no clause mentions forfeiting credits as a penalty.

Using fake, misleading, or inaccurate information in your profile / Impersonating other people or entities / Using unauthorized automated or scripting processes (such as bulk or automated uploading of content through a script) / Using schemes or third-party services to boost account engagement (artificially increasing the number of likes, views, or other metrics". [AUP, last modified Nov 11, 2024](https://www.meshy.ai/acceptable-use-policy)
- AUP section 5 says: "We may take action on your Meshy account if we discover content or behavior that violates this AUP." [AUP](https://www.meshy.ai/acceptable-use-policy)
- AUP section 4 says: "Using Meshy's services to develop any technology or product that is competitive with Meshy or otherwise commercially exploits Meshy is prohibited." [AUP](https://www.meshy.ai/acceptable-use-policy)

**ToS 2.6 Use Restrictions (verbatim, the whole list).** It does not mention bots, scripts, scraping or automation: "You agree you may not use the Service in the following manner or for the following purposes: (i) violate any applicable ... laws or regulations; (ii) reverse engineer, decompile, disassemble, modify, create derivative works of, or otherwise create, attempt to create or derive, or permit or assist any third party to create or derive, the source code underlying the Service; (iii) infringe upon or violate any third party rights ...; (iv) develop or offer competitive products or services or engage in competitive analysis; (v) resell or redistribute the Service or access to the Service; (vi) allow multiple users to use one user account; (vii) use the Service to attempt to or actually deceive or defraud; (viii) introduce any virus, Trojan horse, malware, or other malicious code through the Service; (ix) attempt to gain unauthorized access to or interfere with any parts of the Service; (x) to transmit or submit any sensitive personal data ...; (xi) use generated digital assets to train, develop, or improve AI models that are competitive with Meshy; or (xii) use the Service in violation of Meshy's acceptable use policy ... ("AUP")." [ToS §2.6, updated Sep 19, 2026](https://www.meshy.ai/terms-of-use)

**Consequences (ToS 5):** "We reserve the right to suspend your access to the Service or terminate this Agreement if (i) we need to prevent a credible risk of harm or liability to Meshy or a third party; (ii) you use Meshy in a way that violates our AUP or this Agreement, (iii) we are required to do so by law, or (iv) [insolvency] ... We will take reasonable steps to provide you with written notice prior to such suspension or termination." [ToS §5](https://www.meshy.ai/terms-of-use)

Subscription Features "do not roll over ... once expired, unused Features have no value". Additional Credits "remain available ... for up to one (1) year from the date of purchase". (§2.10) No clause specifically says credits are forfeited on suspension. [ToS §§2.10, 4](https://www.meshy.ai/terms-of-use)

**Meshy's positioning of automation.** The docs say the web app offers no automation ("Automation: Web app No / 3D Agent Limited / API Full") and: "The API suits automation, batch processing, and building 3D generation into your own product." - Meshy officially supports AI agents through its API: an MCP server ("Generate 3D inside Claude, Cursor, and any AI agent") and a CLI, both of which wrap the REST API and need an API key. [Meshy site nav / ToS page header](https://www.meshy.ai/terms-of-use); [docs llms.txt](https://docs.meshy.ai/llms.txt)
- The ToS defines the Service to include "an API, a gallery for sharing and showcasing content and plug-ins". [ToS preamble](https://www.meshy.ai/terms-of-use)

### Inferences
- **Unstated authorization.** "Unauthorized automated or scripting processes" implies some automation is authorized. The obvious authorized routes are the API, the MCP server, the CLI and the official plugins. An agent driving the UI in a real browser is not among them, so Meshy could reasonably call it "unauthorized automated" use. The example given, "bulk or automated uploading of content through a script", points at bulk/scripted activity. A low-volume agent working at human pace on one personal account is the least likely to be flagged or to count as "harmful", but the clause does not exempt it.
- **Not an outright prohibition.** The ToS use-restriction list (§2.6) has no anti-bot or anti-scraping item, unlike many SaaS terms. The penalty language is discretionary ("may disable accounts", "may take action", "reserve the right to suspend"). So "restricted / at Meshy's discretion" fits better than "prohibited".
- **Account sharing is not the issue.** The user is still the account holder and "fully responsible for all use", so an agent acting for the user is not sharing credentials with a non-Authorized User. The rules on multiple users and resale are not triggered.
- **Clause (ix).** "interfere with any parts of the Service" could cover automation that loads Meshy's systems or gets around UI limits (for example, getting past per-day image caps). Human-pace use lowers this risk.
- **Workarounds for paid features.** No clause explicitly bans getting around paid features. Using automation to grab web-only zero-credit actions (free remesh, rigging, animation presets) instead of paying for the API equivalents could be argued to "commercially exploit Meshy" (AUP §4) if done at scale. That reading is speculative.
- **Practical risk.** The worst documented outcome is suspension or termination of the account, with at least "reasonable steps" toward written notice. Because fees are non-refundable and there is no refund clause for termination, a suspended account's remaining paid credits could in practice be lost, even though no clause says so outright.

### Gaps
- I found no separate "API Terms" page and no Meshy statement that the API is the *only* sanctioned automation method. The docs only position it as the automation option.
- I found no Meshy statement (help center, Discord, blog) about browser-automation or AI-agent use of the web UI. Discord is not indexed, and I did not search the help center deeply for this.
- The AUP is dated Nov 2024 and has not been updated alongside the Sep 2026 ToS. Its "unauthorized automated" language comes from before Meshy's own 3D Agent and MCP products.
- No clause specifically covers forfeiting credits on termination.

## (B) Web-app features that are NOT available (or not equivalently available) through the public API

### Takeaway
The public API now covers almost all generation and post-processing (text/image/multi-image to 3D, retexture, remesh, UV unwrap, rigging, animation, text-to-motion, text/image-to-image, multi-color print, printability analyze/repair, auto split, convert, resize, Creative Lab). The web-only features are mostly **interactive editors and workspace tools**: Texture Edit (AI masked retexture, healing, stamp, paint, decals), the mesh Edit tool, Custom Pose, 3D Scenes, AI video, the 3D Agent and its skills/templates/image inpaint, the viewer's printability card and its UV inspection tools, asset library management, community/Discover, DCC/slicer bridges, Meshy Shop printing and team credit limits. **Pricing also differs.** Remesh, Rigging and Animate presets cost 0 credits in the web app but 5, 5 and 3 per action through the API.

### Cited Findings
**API surface, for reference.** The API documents these endpoints: Text to 3D, Image to 3D, Multi-Image to 3D, Remesh, Convert, Resize, UV Unwrap, Retexture, Rigging, Animation, Text to Motion, Text to Image, Image to Image, Multi-Color Print, Analyze Printability, Repair Printability, Auto Split, Creative Lab (Keychain, Fridge Magnet, Figure, Vinyl Figure, Brick Figure, Lamp, Keycap, Collapsible Fidget, Fidget Pixel), Balance, Usage, and the Animation Library catalog. [docs llms.txt](https://docs.meshy.ai/llms.txt)
- The MCP server's tools mirror the REST API, plus a local `meshy_send_to_slicer` that "runs locally and doesn't call the Meshy API". [llms-full.txt, AI Integration](https://docs.meshy.ai/llms-full.txt)

**Web-only features (no matching API endpoint found):**
1. **Texture Edit (AI texture editing / painting on the model).** "Fix or change one area of a model's texture by painting directly on the 3D model, with a real-time preview." Its tools:
   - AI Texture Edit: "Draw a mask on the area you want to change, enter a prompt ... and click Retexture", with an optional reference image. This is masked 3D inpainting.
   - Healing Tool: paints over seams, artifacts and color bleed.
   - Stamp Tool: clone texture from one spot to another.
   - Solid Paint Tool: paint a picked color onto the model.
   - Decal Tool: upload an image and place it, with width, height, rotation and opacity.
   - History: go back to any earlier edit.
   Requirements: "A computer. Texture Edit isn't available on mobile." and "A paid plan to save your edits to the model." Per-edit credit cost is not stated. The API's Retexture replaces the whole texture and has no mask or region parameter. [Texture Edit](https://docs.meshy.ai/en/webapp/guides/texture-edit); [llms-full.txt Retexture params](https://docs.meshy.ai/llms-full.txt)
2. **Mesh "Edit" tool in the viewer.** "To change the mesh shape, click Edit in the viewer toolbar, or edit the model in Blender with Meshy for Blender." No API equivalent. Details and cost are not documented on the pages I fetched. [Texture Edit](https://docs.meshy.ai/en/webapp/guides/texture-edit)
3. **Custom Pose (pose editor before generation).** "Custom Pose sets the exact stance your character is generated in, instead of the pose in your input image." Start from one of 6 presets or adjust each joint. Pose needs a paid plan, and free accounts get limited tries. The API's `pose_mode` accepts only `a-pose`, `t-pose` or empty. [Web Image to 3D](https://docs.meshy.ai/en/webapp/image-to-3d); [llms-full.txt](https://docs.meshy.ai/llms-full.txt)
4. **3D Scenes (Scene compose).** "Arrange several 3D models into one scene by moving, rotating, and scaling them". Includes camera, environment lighting and ground settings, adding community models, and Image Render (an AI render of the scene from a prompt, credits shown before generating). "Can I export a scene layout to a game engine? No. Meshy keeps the scene in the web app." [3D scenes](https://docs.meshy.ai/en/webapp/guides/scene-video/scene-compose)
5. **AI Video generation.** Image to Video and Text to Video, with duration, quality, aspect ratio and audio options. "Video generation needs a paid plan." Charged in credits, with the cost shown before generating. [AI video generation](https://docs.meshy.ai/en/webapp/guides/scene-video/video-generation)
6. **3D Agent (conversational creation).** Covers brainstorming, batch visual concepts with consistent style, chat-to-3D, and in-chat retexture, remesh, split, repair, rig and animate. Also web search for reference images, read-only conversation sharing, Skills (curated presets), 21 official photo-to-3D templates in Discover, free retries of generations (count depends on plan), and per-action credit approval with a per-turn budget. Available on the Free plan since September 2026. Agent-only image tools: "an Inpaint tool that repaints brush-selected areas of an image from a text prompt" and one-click background removal. The API has `remove_background` on Text/Image to Image, but no inpaint endpoint was found. [3D Agent](https://docs.meshy.ai/en/webapp/3d-agent); [Web changelog](https://docs.meshy.ai/en/webapp/changelog); [llms-full.txt changelog](https://docs.meshy.ai/llms-full.txt)
7. **Image generation extras.** Style presets (e.g. "Japanese Anime, Western Realism, or Chibi Blind Box", Nano Banana Pro/2 only), Multi-view (front/side/back), Pose, the "Refine Prompt" toggle, up to 5 image references, and 1–8 images per run. "On the Free and Starter plans, you can generate up to 4 images a day." No style-preset parameter was found in the API's Text to Image docs. [AI image generation](https://docs.meshy.ai/en/webapp/guides/image/ai-image-generation)
8. **Batch Images to 3D UI and multi-generation.** Up to 10 images become 10 models in one run (paid plan). Text to 3D with Meshy 6 can make "up to 10 models from one prompt". The API is one task per request, so the same result needs a client-side loop rather than a missing capability. [Batch Images to 3D](https://docs.meshy.ai/en/webapp/guides/3d-model/batch-images-to-3d); [Web Text to 3D](https://docs.meshy.ai/en/webapp/text-to-3d)
9. **Asset library management.** Search, filters, labels ("up to 20 labels to a model and ... up to 100 labels in total"), list view of version groups, Batch Selection to download, label or delete up to 10 models (Pro+), and Upload of .fbx/.obj/.stl/.gltf/.glb up to 100 MB for post-processing. The API keeps non-Enterprise outputs only 3 days ("Customer Output generated by Customers using the APIs, other than Enterprise Customers, will be deleted three (3) days after it is generated."). The web app stores assets persistently, subject to storage limits. [Assets](https://docs.meshy.ai/en/webapp/guides/platform/asset-management); [ToS §2.5](https://www.meshy.ai/terms-of-use)
10. **Viewer inspection tools.** PBR preview with HDRI switching; View UV with UV Layout, 3D Seams and UV Checker; and a Printability card with "Make Printable", a watertight repair costing 10 credits that needs a paid plan for Meshy-generated models. The API has Analyze and Repair Printability endpoints, so only the visual inspection tools are web-only. [AI Texturing](https://docs.meshy.ai/en/webapp/guides/3d-model/ai-texturing); [Unwrap UV](https://docs.meshy.ai/en/webapp/guides/3d-model/unwrap-uv); [3D printing workflow](https://docs.meshy.ai/en/webapp/guides/use-cases/3d-printing)
11. **Auto Split interactive UI.** Exploded-view slider, Assembled vs On Plate layout, per-part visibility, and Re-split versions. Splitting itself is in the API (Auto Split, 10 credits). The web adds "Send to Printer" to Bambu Studio, OrcaSlicer and others (Pro+). [Auto Split (web)](https://docs.meshy.ai/en/webapp/guides/3d-model/auto-split)
12. **Animate UI with 600+ preset library browsing.** Search and categories (Walk & Run, Daily Actions, Dancing, Fighting, Body Movements), multi-clip "All Added" export, skeleton template choice (e.g. Mixamo), and a saved motion library for Text to Motion results. The API has Animation (by `action_id`) and a library JSON, so the browse UI and multi-clip export packaging are the web-specific parts. "Adding a preset costs no credits." "A few motions are available on every plan, and the rest need a paid plan." [Animate](https://docs.meshy.ai/en/webapp/guides/animate); [Pricing (web)](https://docs.meshy.ai/en/webapp/pricing)
13. **DCC "Bridge" plugins.** Blender, Unity, Unreal, Godot, Maya, 3ds Max, ZBrush, Cascadeur, Omniverse and Roblox; plus slicer integrations (Bambu Studio, Creality Print, Elegoo, OrcaSlicer, Cura, Lychee, Snapmaker, xTool, Flash Studio). These push models from the web app into the tool. The Blender plugin also has local 3D-print prep (Analyze, Clean Up / Make Manifold, Hollow, Align XY, Scale to Volume/Bounds, STL/OBJ/PLY export). [docs sitemap](https://docs.meshy.ai/sitemap.xml); [Meshy for Blender](https://docs.meshy.ai/en/webapp/plugins/blender/introduction); [Model editing](https://docs.meshy.ai/en/webapp/plugins/blender/model-editing)
14. **Community / Discover / Showcase.** Browse, share and download community models, and use community models in Scenes. The ToS covers "Community Content". [meshy.ai llms.txt](https://www.meshy.ai/llms.txt); [3D scenes](https://docs.meshy.ai/en/webapp/guides/scene-video/scene-compose)
15. **Meshy Shop 3D printing service.** Order physical prints of your models, fulfilled by a third party under the "Terms of Service Addendum for 3D Printing Services" (last updated Sep 19, 2026). [ToS Printing Addendum](https://www.meshy.ai/terms-of-use)
16. **Creative Lab categories with no API.** The web changelog lists Plant Pot, Tabletop Terrain, Twist Egg, Golden Boot Keychain and Pet Keepsake. The API covers Keychain, Fridge Magnet, Figure, Vinyl Figure, Brick Figure, Lamp, Keycap and the two Fidgets. [Web changelog](https://docs.meshy.ai/en/webapp/changelog); [docs llms.txt](https://docs.meshy.ai/llms.txt)
17. **Team web credit limits per member.** "A limit caps the credits a member spends in the web app and the 3D Agent, separately from API key credit limits." [Web changelog, Sep 2026](https://docs.meshy.ai/en/webapp/changelog)
18. **Free 3D tools on the website.** File Converter (batch conversion), Online 3D Viewer, 3D Model Splitter, 3D Text Generator and 3D File Compressor. The API's Convert costs 1 credit per task. [meshy.ai llms.txt](https://www.meshy.ai/llms.txt); [API pricing](https://docs.meshy.ai/api/pricing.md)

### Inferences
- Current DCC plugins spend no API credits. Any generation happens in the web app and is charged as web credits. The bridge transfer itself appears free but needs a Pro+ plan.
- For a game pipeline, the main web-only capabilities with no API substitute are Texture Edit (masked AI retexture, healing, decals), Custom Pose, the mesh Edit tool, Scenes/Video, and the 3D Agent's inpaint, skills and free retries. Everything else can be reproduced through the API, though often at a higher credit cost (remesh, rig, animate).
- The gap between zero web cost and paid API cost for remesh, rig and animate is the main economic reason someone might automate the web UI. It is also the kind of use Meshy could treat as exploiting web pricing (see part A).

### Gaps
- Credit cost per Texture Edit operation, mesh Edit tool, Scene Image Render and Video generation: the docs say only that the cost is "shown before you generate".
- Details of the viewer's mesh "Edit" tool: no dedicated docs page was found in the sitemap.
- Whether API credits and web subscription credits are one shared pool or separate balances. The API docs say to "buy API credits", and the team docs mention separate "API key credit limits", but no explicit statement was found. Verify on the Pricing page or Help Center.
- I could not reconcile the web app's "Starter" plan mention (in the image-gen daily cap) with the plan list (Free/Pro/Premium/Ultra/Studio/Enterprise).
- Discord announcements were not searched (not indexed).
