# Waystone audio credits

There are no audio files in this folder. Every sound in the demo is synthesized at runtime with the Web Audio API in `src/game/audio.ts`, so nothing is downloaded and there is nothing third-party to license. Total size on disk: 0 bytes.

| Sound | How it is made | Source | Licence |
|---|---|---|---|
| Wind loop (rises with the storm) | White noise through a band-pass filter swept by a slow LFO | Original, made in code for this demo | CC0-1.0 |
| Campfire | Low-passed noise bed plus random short band-passed crackles, louder near the camp | Original, made in code | CC0-1.0 |
| Footsteps | Short low-passed noise thumps, heavier for Anchorkin | Original, made in code | CC0-1.0 |
| Swing | Band-pass noise sweep | Original, made in code | CC0-1.0 |
| Hit / hurt | Triangle or sawtooth pitch drop plus a noise burst | Original, made in code | CC0-1.0 |
| Pickup | Four-note sine arpeggio | Original, made in code | CC0-1.0 |
| Gust, roar, charge, slam | Noise sweeps and falling sawtooth / sine tones | Original, made in code | CC0-1.0 |
| Theme (start and ending) | Pentatonic triangle melody over a sine pad | Original, made in code | CC0-1.0 |

If recorded CC0 samples (for example from Kenney or freesound CC0) are added here later, list each file with its source URL, author and licence in this table.
